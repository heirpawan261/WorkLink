# WorkLink Machine Learning Module (`ml/`)

This directory houses the machine learning models, training scripts, dataset preprocessors, and inference pipelines for WorkLink.

## Directory Structure (Planned)

```
ml/
├── models/         # Serialized model artifacts (.pt, .onnx, .joblib)
├── notebooks/      # Data exploration & training notebooks
├── src/            # Core ML library modules
│   ├── dataset.py  # Data loaders and transformers
│   ├── train.py    # Training execution scripts
│   └── predict.py  # Inference handlers
└── requirements.txt # Python dependencies for ML workloads
```
